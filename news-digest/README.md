# 네이버 뉴스/블로그/카페 일일 요약

매일 [keywords.md](./keywords.md)의 검색어로 네이버 뉴스·블로그·카페 글을 검색해서, 핵심 내용만 골라 하루 한 페이지(`daily/YYYY-MM-DD.md`)로 정리해두는 폴더입니다.
형식 예시는 [daily/TEMPLATE.md](./daily/TEMPLATE.md) 참고 (실제 데이터 아님, 형식 견본).

## 원칙
- 원문 전문을 복사하지 않습니다. 제목 + 1~2문장 핵심 요약 + 원문 링크만 남깁니다.
- 사실관계가 불확실하거나 출처가 불분명한 글은 제외합니다.
- 실제 사이트 "뉴스" 게시판에 올릴지는 이 파일을 사람이 검토한 뒤 별도로 결정합니다 (자동 게시 아님).

## 반복 기사 억제 규칙 (`seen-topics.json`)

같은 정책/뉴스 사안이 여러 매체에서 반복 보도되거나 여러 날에 걸쳐 계속 다뤄지는 경우가 많습니다.
[seen-topics.json](./seen-topics.json)에 뉴스·정책성 사안(블로그 실무 팁·후기는 대상 아님 — 매번 다른 사람의
다른 경험담이라 "반복 기사"가 아님)의 등장 횟수를 기록해두고, 요약본 작성 시 다음 규칙을 따릅니다.

1. 오늘 수집된 뉴스가 `seen-topics.json`에 있는 사안과 핵심 내용이 같다면(재기사화·후속 단신 등)
   `count`를 1 늘리고 `lastSeen`을 갱신합니다.
2. `count`가 **5 이상**이면 — 검색 자체는 계속하지만(키워드에서 빼지 않음) — 그날 요약(`daily/*.md`)에는
   **포함하지 않습니다**. 이미 충분히 다뤄진 사안이라 매일 반복 노출할 필요가 없기 때문입니다.
3. 다만 같은 사안이라도 **새로운 구체적 내용**(금액·일정·결정 변경 등 실제 업데이트)이 나오면 새 소식으로
   취급해 요약에 포함하고, 해당 항목의 `summary`를 갱신하면서 `count`를 1로 리셋합니다.
4. `key`는 사람이 봐도 알아볼 수 있는 짧은 slug(기관명-사안-핵심어)로, 요약 작성자가 그때그때 판단해 부여합니다.

## 대상 콘텐츠

`keywords.md`는 아래 성격의 정보를 모두 다룹니다 (분류는 편의상이며 검색 자체는 구분 없이 전체 진행):
- 비자/체류자격/노동/다문화 관련 뉴스·정책
- 한국 생활 실무 정보 (병원, 핸드폰, 서류·행정 등)
- 국가별(동남아·중앙아시아) 커뮤니티 소식
- 대학 입학/교환학생 모집 공고
- 관광지·맛집·할인혜택 정보

## 아직 필요한 것: NAVER API HUB 검색 API 키

2026년부터 네이버 검색(뉴스/블로그/카페) API는 기존 개발자센터(developers.naver.com)가 아니라
**네이버클라우드플랫폼의 "NAVER API HUB"**에서 발급받습니다. 개발자센터 애플리케이션 등록 화면에는
더 이상 "검색" 항목이 없습니다 — 아래 새 경로로 진행해주세요.

1. https://console.ncloud.com 접속 → 네이버클라우드플랫폼 계정으로 로그인 (없으면 가입 필요, 본인인증/카드등록이 요구될 수 있음)
2. NAVER API HUB 서비스 **이용 신청**
3. **Application 등록** — 사용할 API에서 **검색** 선택
4. 등록하면 **Client ID / Client Secret이 자동 발급**되어 화면에 표시됨

키를 받으시면 저에게 알려주세요 (Client ID는 공유해도 괜찮지만, **Client Secret은 채팅에 붙여넣지 마시고**
`.env.local`에 직접 넣어주시는 걸 권장드립니다 — 이건 API 호출 권한을 가진 진짜 비밀키입니다).

```bash
# .env.local에 추가
NAVER_SEARCH_CLIENT_ID=발급받은_값
NAVER_SEARCH_CLIENT_SECRET=발급받은_값
```

> 참고: 새 API는 인증 헤더도 바뀌었습니다 (`X-Naver-Client-Id`/`Secret` → `X-NCP-APIGW-API-KEY-ID`/`X-NCP-APIGW-API-KEY`).
> 스크립트 작성 시 반영합니다.

## 진행 상태
1. ✅ 네이버 검색 API를 호출해 키워드별 결과를 가져오는 스크립트 — [fetch.mjs](./fetch.mjs)
   (`node --env-file=.env.local news-digest/fetch.mjs` → `daily/raw-<date>.json`)
2. ✅ 결과를 걸러서(중복 제거·반복 기사 억제) 핵심만 요약해 `daily/YYYY-MM-DD.md`로 저장 — 지금은 사람이 직접 검토하며 작성
3. ⏳ 매일 자동으로 실행되도록 예약 작업(클라우드 스케줄) 설정 — 진행 중
